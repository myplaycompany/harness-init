# {project_name} — 도메인 지식

> **이 문서는 의미(semantics) 전용이다.**
>
> 엔티티 필드 목록, 관계, 호출 경로, 영향 범위 같은 **구조**는 여기 적지 않는다.
> 스키마 파일이 진실의 원천이고, 구조 질의는 codegraph가 항상 최신으로 답한다:
>
> ```
> codegraph explore "<질문>"     # 관련 심볼 + 소스 + 호출 경로 한 번에
> codegraph impact <심볼>        # 이걸 바꾸면 어디가 영향받나
> codegraph callers <심볼>       # 누가 호출하나
> ```
>
> 여기에는 **코드를 아무리 읽어도 알 수 없는 것**만 적는다.
> 자세한 역할 분담은 `.claude/rules/knowledge.md` 참조.
